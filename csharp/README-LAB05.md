# Лабораторная работа 5 — C#

## Реализация
- `ICombatant` реализован классами `Warrior` и `Healer`; базовый класс `BaseUnit` плюс интерфейс демонстрируют множественную реализацию контракта.
- `Lab05.Run()` вызывает функциональность через интерфейс.
- `override` демонстрирует позднее связывание, `new`/скрытие `BindingLabel` — раннее.
- Проверки типа выполняются через `is` и `as`.
- `ICombatant : IComparable<ICombatant>` позволяет сортировать реализации.
- `IAbilityStrategy` имеет две стратегии, переключаемые во время выполнения.
- Собственное исключение обрабатывается через `try/catch`, завершающая логика — в `finally`.

## Сборка и запуск
Из корня репозитория:
```bash
dotnet build csharp
dotnet run --project csharp
```
