# Magic Step — лабораторные работы на C#

Этот README относится только к C#-версии проекта. Исходный код расположен в `csharp/`; проект использует .NET 8.

## Структура
- `BaseUnit.cs` — абстрактный базовый класс и общие контракты.
- `Warrior.cs`, `Archer.cs`, `Mage.cs`, `Healer.cs` — конкретные боевые единицы.
- `Cell.cs`, `Battlefield.cs` — клетка и игровое поле.
- `BattleLog.cs` — пример `IDisposable` и `using`.
- `Program.cs` — демонстрация лабораторных работ.
- `MagicStep.csproj` — настройки .NET.

## Лабораторная работа 5
Функциональность ЛР 5 должна быть встроена в существующие файлы; отдельного `Lab05.cs` не требуется.

- `ICombatant` реализуется `Warrior` и `Healer` вместе с наследованием от `BaseUnit`.
- Невиртуальный метод и скрытие через `new` демонстрируют раннее связывание; `override` — позднее.
- Проверка типов выполняется через `is` и `as`.
- `IComparable<ICombatant>` позволяет сортировать бойцов.
- `IAbilityStrategy` и две реализации демонстрируют смену поведения.
- Пользовательское исключение обрабатывается в `try/catch`, а `finally` выполняется после обработки; нарушение правила — действие мёртвого бойца.

Примеры предыдущих лабораторных (копирование, строки, равенство, статические члены, `using`, игровое поле) должны оставаться в `Program.cs`.

## Сборка и запуск
Нужен .NET SDK 8.0 или новее. Из корня репозитория:

```bash
dotnet build csharp
dotnet run --project csharp
```
