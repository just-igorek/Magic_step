# Лабораторные работы — C++17

Этот README относится только к C++-версии проекта. Заголовки находятся в `include/battle/`, реализации — в `src/battle/`, точка входа — `main.cpp`.

## Структура проекта
- `BaseUnit` — абстрактный базовый класс боевой единицы.
- `Warrior`, `Archer`, `Mage`, `Healer` — конкретные юниты.
- `Cell`, `Battlefield` — клетка и игровое поле.
- `UnitProfile` — профиль юнита для демонстрации копирования.

## Лабораторная работа 5
Функциональность ЛР 5 должна находиться в существующих файлах; отдельные файлы `lab05` не используются.

- `ICombatant` — абстрактный интерфейс без полей и с виртуальным деструктором.
- `Warrior` и `Healer` реализуют интерфейс и наследуются от `BaseUnit` (множественное наследование).
- Невиртуальный метод и скрытие имени показывают раннее связывание; виртуальный `Attack()` — позднее.
- `dynamic_cast` демонстрирует проверку динамического типа.
- `IAbilityStrategy`, две стратегии и `std::unique_ptr` демонстрируют смену поведения.
- Пользовательское исключение обрабатывает реальное нарушение правила; конкретный тип перехватывается до `std::exception`.
- Сортировка бойцов выполняется через интерфейс.

Примеры предыдущей лабораторной (полиморфизм, виртуальный деструктор, копирование, строки, `this`, статические члены и игровое поле) должны оставаться в `main.cpp`.

## Сборка и запуск
Нужен GCC или Clang с поддержкой C++17. Из корня репозитория:

```bash
mkdir -p build
g++ -std=c++17 -Wall -Wextra -pedantic -Iinclude main.cpp src/battle/*.cpp -o build/battle
./build/battle
```
