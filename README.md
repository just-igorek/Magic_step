# Бой отрядов

Пошаговая тактическая игра с консольным интерфейсом на C++ и C#.

Курсовой проект — демонстрация объектно-ориентированного проектирования
на примере пошагового сражения двух отрядов на клеточном поле.

**Выполняет:** Елунин Игорь

---

## О проекте

Приложение моделирует пошаговый бой двух отрядов на клеточном поле.
Проект построен вокруг иерархии боевых единиц и демонстрирует
основные принципы ООП:

- **Абстракция** — базовый класс `Unit` задаёт общий интерфейс всех юнитов.
- **Наследование** — `Warrior`, `Archer`, `Mage`, `Healer` наследуют `Unit`.
- **Полиморфизм** — `Battle` работает с юнитами через указатели на базовый класс.
- **Инкапсуляция** — состояние и логика юнита скрыты внутри класса,
  а управление боем сосредоточено в `Battle`.

Архитектура соответствует принципу открытости/закрытости (SOLID):
добавление нового класса юнита или эффекта **не требует изменения
существующего кода**.

## Игровой процесс

1. Пользователь запускает программу и видит меню: **собрать отряд** или **выйти**.
2. Выбирает юнитов из доступных классов: `Warrior`, `Archer`, `Mage`, `Healer`.
3. Расставляет отряд на поле.
4. Начинается бой.

**Ход игрока:**
- выбрать юнита;
- выбрать действие: переместиться, атаковать, применить способность
  или пропустить ход.

**Ход ИИ:**
- каждый юнит ищет ближайшего врага;
- атакует, если враг в радиусе;
- иначе делает шаг в сторону цели.

Юниты получают урон, накладывают эффекты и погибают.
Бой завершается, когда все юниты одной из сторон уничтожены.
После завершения `Battle` определяет победителя и выводит результат.

## Архитектура

Ключевые сущности:

| Класс | Роль |
|---|---|
| `Unit` (абстрактный) | Общий интерфейс: `attack()`, `useAbility()`, `takeDamage()`, `isAlive()` |
| `Warrior`, `Archer`, `Mage`, `Healer` | Конкретные классы юнитов, реализуют поведение по-своему |
| `Effect` (абстрактный) | Базовый класс временных состояний |
| `Poison`, `Stun`, `Shield`, `Regen` | Конкретные эффекты |
| `Squad` | Хранит отряд, проверяет состояние боя (`isFinished()`) |
| `Battlefield` | Хранит поле и юнитов, отображает состояние через `print()` |
| `Battle` | Контроллер: управляет жизненным циклом боя |

**Взаимодействие сущностей:**

`Battle` выступает в роли контроллера. В момент запуска пользователь
собирает отряд, `Battle` расставляет юнитов через `Battlefield`
и запускает игровой цикл. На каждом шаге цикла `Battle`:

1. запрашивает у `Battlefield` отображение текущего состояния через `print()`;
2. получает от пользователя ход и парсит его в действие над выбранным `Unit`;
3. передаёт ход юниту для проверки (`canMove()`, `canAct()`) и применения
   (`attack()`, `moveTo()`);
4. проверяет состояние боя через `isFinished()` у `Squad`.

`Battle` управляет процессом, `Unit` инкапсулирует логику и состояние
конкретной боевой единицы, а `Effect` служит для передачи временных
состояний между юнитом и правилами боя — обеспечивая единообразие
применения эффектов для всех типов юнитов.

## Границы проекта

**Входит:**
- консольный интерфейс;
- пошаговый бой игрока против ИИ;
- классы юнитов: воин, лучник, маг, медик;
- эффекты: яд, оглушение, щит, регенерация;
- базовая логика ИИ: поиск ближайшего врага, атака в радиусе, шаг к цели.

**Не входит:**
- графический интерфейс;
- сетевая игра и многопользовательский режим;
- сохранение и загрузка состояния боя между сессиями;
- система рейтингов;
- анимации и звук;
- сложный искусственный интеллект.
